LEAN ✓Rather（2026）问一般位置多项式 ψ(G) = Σ αₖ xᵏ（αₖ 是 k 元一般位置集的个数）在哪些图类上只有实根。答案：连通图的 ψ(G) 只有实根当且仅当 G 是完全图。前三个系数是 1、n、n(n − 1)/2；若根全是实数，Newton 不等式迫使 ψ 的次数等于 n，也就是全部顶点处于一般位置，连通的非完全图做不到；完全图的 ψ = (1 + x)ⁿ。已冻结：Rather (2026) asked on which graph classes the general position polynomial ψ(G) = Σ αₖ xᵏ (αₖ counts general position sets of size k) is real-rooted. Answer: for a connected graph, ψ(G) is real-rooted exactly when G is complete. The first three coefficients are 1, n, n(n − 1)/2; if all roots are real, Newton’s inequality forces deg ψ = n, i.e. the whole vertex set in general position, which no connected non-complete graph has; for the complete graph ψ = (1 + x)ⁿ. Frozen: RatherRealRootedComplete.result

Without x, the 8 vertices A ∪ B are in outer general position; in G a five-colouring makes every pair of equal colour blocked by some shortest path, so gp₀(G) ≤ 5, while 8 > 5 + 2. 在连通图里，顶点 v 落在 u、w 之间的最短路上当且仅当 d(u, v) + d(v, w) = d(u, w)。顶点集 S 处于一般位置，是说 S 里没有三个不同的点满足这个等式。三个问题都围绕这个定义。

  1. 移动机器人。每个顶点上最多一个机器人；一步是把一个机器人沿边移到空顶点，并且移动后的集合仍在一般位置。若一串这样的步能让每个顶点都被某个机器人到过，就说起始集合是移动的。移动一般位置数 Mob_gp(G) 是能做到这件事的最多机器人数。
  2. 柱面 C₇ □ Pₛ 与 C₁₀ □ Pₛ（已冻结）。顶点是 (列, 行)，列沿 r 边形绕一圈，行沿 s 个顶点的路排开。Lean 证明：五个一般位置的顶点在不同的行，列号构成公差 ±2 或 ±3 的等差数列；任何横向移动都会破坏一般位置，所以五个机器人只能上下移动，空着的列永远到不了；六个顶点不可能处于一般位置。四个机器人的走法：两行一组，四次横移把整组转动一格，转 r 次走遍这两行，再用四次竖移进入下一组。
  3. 一般位置多项式（已冻结）。ψ(G) = Σ αₖ xᵏ，αₖ 是 k 元一般位置集的个数。任意两个点总在一般位置，所以 α₀ = 1、α₁ = n、α₂ = n(n − 1)/2。若 ψ 的根全是实数（系数为正，根就都是负数），Newton 不等式 α₁² ≥ α₀α₂ · 2d/(d − 1) 化简为 d ≥ n，d 是 ψ 的次数，即最大一般位置集的大小。于是全部顶点处于一般位置；连通的非完全图里，最短路上相邻的三个点就违反这一点。完全图的 ψ = (1 + x)ⁿ，只有根 −1。
  4. 外部一般位置（已冻结的反例）。S 处于外部一般位置，是说对 S 里的每个 u 与图里任何 v，u 到 v 的最短路都不经过 S 里别的点。最大的这种集合的大小记为 gp₀。删去 x 后 A ∪ B 是 8 元外部一般位置集；加上 x 后，A 与 B 之间出现一条经过 x 的短路，页面按五色染色逐类显示：每对同色顶点都有一个第三点把它们挡住，所以每种颜色最多选一个。
  5. 页面怎么算。距离用广度优先搜索；机器人的走法按 Lean 里的构造逐步重放，每一步都重新检查一般位置；五个机器人的可达配置用广度优先搜索列出；ψ 的系数由枚举所有子集得到，根用 Aberth 迭代求；外部一般位置数用冲突图上的最大独立集穷举。这些都是页面数值。
  6. 边界。环面上的值，以及删点时外部一般位置数的正确上界，都还未决。

In a connected graph, a vertex v lies on a shortest path between u and w exactly when d(u, v) + d(v, w) = d(u, w). A vertex set S is in general position when no three distinct vertices of S satisfy this equation. All three problems build on this definition.

  1. Mobile robots. Each vertex holds at most one robot; a move takes one robot along an edge to an empty vertex, and the new set must still be in general position. A starting set is mobile if some sequence of moves lets every vertex be visited by some robot. The mobile general position number Mob_gp(G) is the largest number of robots that can do this.
  2. The cylinders C₇ □ Pₛ and C₁₀ □ Pₛ (frozen). Vertices are (column, row): columns go round an r-cycle and rows along a path of s vertices. Lean proves: five vertices in general position lie in distinct rows, and their columns form an arithmetic progression with step ±2 or ±3; any sideways move breaks general position, so five robots can only move up and down and an empty column is never reached; no six vertices are in general position. The four-robot route: take two rows at a time, four sideways moves turn the group by one column, r turns cover both rows, and four vertical moves step to the next pair of rows.
  3. The general position polynomial (frozen). ψ(G) = Σ αₖ xᵏ, where αₖ counts general position sets of size k. Any two vertices are in general position, so α₀ = 1, α₁ = n, α₂ = n(n − 1)/2. If all roots of ψ are real (with positive coefficients they are then negative), Newton’s inequality α₁² ≥ α₀α₂ · 2d/(d − 1) reduces to d ≥ n, where d = deg ψ is the size of a largest general position set. So the whole vertex set is in general position, and in a connected non-complete graph three consecutive vertices of a shortest path violate that. For the complete graph ψ = (1 + x)ⁿ, whose only root is −1.
  4. Outer general position (a frozen counterexample). S is in outer general position when, for every u in S and any vertex v, no shortest path from u to v passes through another vertex of S. The largest such set has size gp₀. Without x, A ∪ B is an outer set of 8; with x there is a short route between A and B through x, and the page shows the five-colouring class by class: every pair of equal colour has a third vertex blocking it, so at most one vertex of each colour can be chosen.
  5. How the page computes. Distances come from breadth-first search; the four-robot route replays the Lean construction step by step, re-checking general position after every move; the reachable five-robot configurations are listed by breadth-first search; the coefficients of ψ come from enumerating all subsets and its roots from Aberth iteration; the outer numbers come from an exhaustive maximum independent set in the conflict graph. All of these are page numerics.
  6. Limits. The values on tori and a correct bound for outer general position under vertex deletion remain open.
