理论接口 · 这个页面在演示什么Theory interface · what this page shows

回文是正读反读一样的词，比如 aba、abba。任何词都能切成若干个回文（单个字母就是回文），最少要切几块叫它的回文长度。对一个无限词 u，记 P(n) 为长 n 的前缀的回文长度。页面用回文树（eertree）一次算出所有前缀的 P(n)：每读一个字母，就遍历以它结尾的全部回文后缀，取 P(n) = min P(n − |回文|) + 1，并记下最优的那一刀。三维视图把前缀的字母排开，最优切分的每一块画成一座拱桥。

  1. 两个词。倍周期词是 a → ab、b → aa 从 a 出发反复替换的极限：abaaabababaaabaa…；第 n 个字母（从 0 数）是 b 当且仅当 n + 1 含有奇数个因子 2。斐波那契词是 a → ab、b → a 的极限：abaababaabaab…（本库把字母编码成 true/false：第 i 个字母是 a 当且仅当 i 的 Zeckendorf 表示不含 1；字母叫什么不影响回文长度）。
  2. 猜想 17（已冻结的证明）。Frid、Laborde、Peltomäki 证明了只含有限多个回文的 k-自动词，前缀回文长度都是 k-正则的；倍周期词含有无穷多个回文，他们的计算实验提示它不是 2-正则的，于是猜测（Theoret. Comput. Sci. 891, 13–23 (2021)，arXiv:2009.02934，猜想 17）：差分 d(n) = P(n + 1) − P(n) 不是 2-自动的。一个序列是 2-自动的，当且仅当它的 2-核——全部子序列 n ↦ d(2ᵉn + r)，0 ≤ r < 2ᵉ——只有有限多个。本库证明 2-核是无穷的（PrefixPalindromicLengthNotAutomatic.result），并更强地证明 P 的 2-核张成无穷维空间，所以 P 不是 2-正则的（SparseKernelRank.stronger_PPL_kernel_span）。2-核模式数的是有限窗口里不同子序列的个数，只是旁证；无穷性来自证明，不来自这些数。
  3. 下界与精确值（已冻结）。每切掉一个回文后缀，⌊(n + 1)/2⌋ 的带符号二进制权重 F 最多降 1，所以 P(n) ≥ F(n)（SignedCutLowerBound）。在稀疏地址 N(a, b) 上，这个下界与构造的切分配合给出精确值 P(N(a, 2a − 1)) = 3a 与 P(N(a, b)) = a + b（SparseExactDiagonal、SparseExactOffDiagonal），这些精确值正是 2-核秩无界的来源。页面算到 n = 3·10⁵：P − F 只取 0、1、2，第一次取 2 在 n = 72——这是有限范围的读数，P ≤ F + 2 是否总成立仍是开放问题。
  4. Frid 的斐波那契猜想（已冻结的证明）。Frid 猜测斐波那契词长为 (100)2k−1101（斐波那契记数，权重 1, 2, 3, 5, 8, …）的前缀不能切成至多 2k 个回文（Numeration 2018 摘要，猜想 2）。本库证明它恰好需要 2k + 1 个（FridPrefixPalindromicLength.result），而这个长度等于 F6k+3/2（FridNumerals.frid_numeral_twice）：k = 1, 2, 3, 4 时是 17、305、5473、98209。Ambrož、Kadlec、Masáková、Pelantová 指出，这个猜想若成立就给出 limsup 的下界 1/(3 log φ)（arXiv:1812.00711）；页面画出的斜率 1/(3 ln φ) 是由此推出的参考线，没有形式化。
  5. 模型边界。页面上的 P(n) 是对有限前缀的精确计算；2-核计数、P − F 的取值范围、各 P 值第一次出现的位置都只是有限范围的读数，不能代替证明。

A palindrome reads the same forwards and backwards, like aba or abba. Every word can be cut into palindromes (a single letter is one), and the least number of pieces is its palindromic length. For an infinite word u, write P(n) for the palindromic length of its prefix of length n. The page computes P(n) for every prefix at once with a palindromic tree (eertree): after each letter it runs through all palindromic suffixes ending there, takes P(n) = min P(n − |palindrome|) + 1, and records the best cut. The 3D view lays out the letters of the prefix and draws each block of an optimal cut as an arch.

  1. Two words. The period-doubling word is the limit of repeatedly substituting a → ab, b → aa starting from a: abaaabababaaabaa…; its letter at position n (from 0) is b exactly when n + 1 has an odd number of factors 2. The Fibonacci word is the limit of a → ab, b → a: abaababaabaab… (this library codes the letters as true/false: the letter at i is a exactly when the Zeckendorf representation of i has no 1; the names of the letters do not affect palindromic length).
  2. Conjecture 17 (a frozen proof). Frid, Laborde and Peltomäki proved that the prefix palindromic length of every k-automatic word with only finitely many palindromes is k-regular; the period-doubling word has infinitely many palindromes, their computations suggested it is not 2-regular, and they conjectured (Theoret. Comput. Sci. 891, 13–23 (2021), arXiv:2009.02934, Conjecture 17): the differences d(n) = P(n + 1) − P(n) are not 2-automatic. A sequence is 2-automatic exactly when its 2-kernel, the set of subsequences n ↦ d(2ᵉn + r) with 0 ≤ r < 2ᵉ, is finite. This library proves the 2-kernel is infinite (PrefixPalindromicLengthNotAutomatic.result), and more strongly that the 2-kernel of P spans an infinite-dimensional space, so P is not 2-regular (SparseKernelRank.stronger_PPL_kernel_span). The 2-kernel mode counts distinct subsequences on a finite window, which is only circumstantial evidence; infinitude comes from the proof, not from these counts.
  3. A lower bound and exact values (frozen). Cutting off one palindromic suffix lowers the signed binary weight F of ⌊(n + 1)/2⌋ by at most 1, so P(n) ≥ F(n) (SignedCutLowerBound). At the sparse addresses N(a, b) this bound and explicit cuts give the exact values P(N(a, 2a − 1)) = 3a and P(N(a, b)) = a + b (SparseExactDiagonal, SparseExactOffDiagonal), and these exact values are what makes the rank of the 2-kernel unbounded. The page computes up to n = 3·10⁵: P − F takes only the values 0, 1, 2 and first reaches 2 at n = 72; this is a reading on a finite range, and whether P ≤ F + 2 always holds is open.
  4. Frid’s Fibonacci conjecture (a frozen proof). Frid conjectured that the prefix of the Fibonacci word of length (100)2k−1101 (in Fibonacci numeration, weights 1, 2, 3, 5, 8, …) cannot be cut into at most 2k palindromes (Numeration 2018 abstracts, Conjecture 2). This library proves it needs exactly 2k + 1 (FridPrefixPalindromicLength.result), and the length equals F6k+3/2 (FridNumerals.frid_numeral_twice): 17, 305, 5473, 98209 for k = 1, 2, 3, 4. Ambrož, Kadlec, Masáková and Pelantová noted that the conjecture would give the lower bound 1/(3 log φ) on the limsup (arXiv:1812.00711); the slope 1/(3 ln φ) drawn on the page is a guide derived from it, not formalized.
  5. Model limits. The values P(n) on the page are exact computations for finite prefixes; the 2-kernel counts, the range of P − F and the first positions of each value of P are readings on a finite range and cannot replace a proof.
