LEAN ✓E = ℓ²(ℤ × ℤ; ℂ)。对任意 r ∈ ℕ、g ∈ ℝ、h : ℤ² → ℂ 与 ℓ : ℤ³ → ℂ，若有限力程（|x − y| > r 时 h(x, y) = 0；max{|x − k|, |y − k|} > r 时 ℓ(k, x, y) = 0）并且平移不变（h(x + 1, y + 1) = h(x, y)，ℓ(k + 1, x + 1, y + 1) = ℓ(k, x, y)），则存在有界算子 t : E → E，使 (tρ)(x, y) 等于 Lindblad 矩阵元 −i(hρ − ρh)(x, y) + g Σ_k [ℓ_k ρ ℓ_k* − ½{ℓ_k*ℓ_k, ρ}](x, y)，并且 0 ∈ σ(t)。定理不要求秩 1、不要求 h 自伴，也不要求 g 的符号。已冻结：E = ℓ²(ℤ × ℤ; ℂ). For every r ∈ ℕ, g ∈ ℝ, h : ℤ² → ℂ and ℓ : ℤ³ → ℂ that have finite range (h(x, y) = 0 when |x − y| > r; ℓ(k, x, y) = 0 when max{|x − k|, |y − k|} > r) and are translation invariant (h(x + 1, y + 1) = h(x, y), ℓ(k + 1, x + 1, y + 1) = ℓ(k, x, y)), there is a bounded operator t : E → E whose entries (tρ)(x, y) are the Lindblad matrix entries −i(hρ − ρh)(x, y) + g Σ_k [ℓ_k ρ ℓ_k* − ½{ℓ_k*ℓ_k, ρ}](x, y), and 0 ∈ σ(t). The theorem needs no rank-one condition, no self-adjoint h and no sign of g. Frozen: LatticeLindbladianZeroSpectrum.result
LEAN ✓证明的机制（同一模块里一起冻结的私有引理）：P_n 是对角线上 |x| ≤ n 处取 1 的核，⟨P_n, ρ⟩ = Σ_{|x|≤n} ρ(x, x)，‖P_n‖² = 2n + 1；完整的迹把每个矩阵单位送到 0；所以截断迹 ⟨P_n, tρ⟩ 只剩靠近 ±n 的系数，存在与 n 无关的 K 使 |⟨P_n, tρ⟩| ≤ K‖ρ‖；若 t 有逆 S，取 ρ = SP_n 得 √(2n + 1) ≤ K‖S‖ 对所有 n 成立，矛盾。冻结：The mechanism of the proof (private lemmas frozen in the same module): P_n is the kernel equal to 1 on the diagonal for |x| ≤ n, ⟨P_n, ρ⟩ = Σ_{|x|≤n} ρ(x, x) and ‖P_n‖² = 2n + 1; the full trace sends every matrix unit to 0; so the truncated trace ⟨P_n, tρ⟩ keeps only coefficients near ±n, and some K independent of n gives |⟨P_n, tρ⟩| ≤ K‖ρ‖; if t had an inverse S, taking ρ = SP_n gives √(2n + 1) ≤ K‖S‖ for every n, a contradiction. ARGUED卷宗中的论证（未形式化）：E 与 Hilbert–Schmidt 算子空间等距同构，谱随之搬运，所以对 H 自伴、g > 0 的情形这正回答了 Klausen 的问题；再用原文的定理 no_gap 得到“无能隙，或核是无穷维”。在 Klausen 的例子 H = S + S*、L_k = |δ_k⟩⟨δ_k|、g > 0 中，tρ = 0 迫使 ρ 是对角且对角线为常数，不在 E 里——所以 0 在谱里却不是 E 中的本征值。Arguments in the dossier (not formalized): E is isometric to the Hilbert–Schmidt operators and the spectrum transfers, so for self-adjoint H and g > 0 this answers Klausen’s question; the source’s theorem no_gap then gives “gapless, or an infinite-dimensional kernel”. In Klausen’s example H = S + S*, L_k = |δ_k⟩⟨δ_k|, g > 0, tρ = 0 forces ρ to be diagonal with a constant diagonal, which is not in E — so 0 lies in the spectrum without being an eigenvalue in E.

一条无限长的原子链，每个格点 x 上可以有一个粒子；开放量子系统的状态写成核 ρ(x, y)，演化由 Lindblad 生成元 t 决定：哈密顿量 H 让粒子相干地跳，跳跃算子 L_k 描述环境的作用。Klausen 研究这种生成元的谱，问：只要力程有限、平移不变（并且 L_k 秩 1），0 是否一定在谱里？本库在 Lean 里证明是的，而且连秩 1、H 自伴、g > 0 都不需要。

  1. 为什么会想到 0。Lindblad 演化保持迹，所以完整的迹把 t 的输出送到 0：Σ_x (tρ)(x, x) = 0。但单位矩阵（迹对应的核）不在 ℓ² 里，所以这不能直接说明 t 不可逆。
  2. 截断。把迹截到 |x| ≤ n：P_n 是对角线上 2n + 1 个 1，它在 ℓ² 里，范数 √(2n + 1)（三维视图的青柱，左下图的青线）。
  3. 只剩边界。Σ_{|x|≤n} (tρ)(x, x) 把每个 (tρ)(x, x) 用到的系数（灰柱）加起来。内部的系数两两抵消，因为完整的迹把每个矩阵单位送到 0；只有靠近 (±n, ±n) 的几个系数留下（品红柱），全落在 Lean 证明给出的琥珀区域里。它们的范数不随 n 增长（左下图品红线）。
  4. 没有逆。若 t 有逆 S，令 ρ = SP_n，则 ‖P_n‖² = ⟨P_n, tρ⟩ ≤ K‖S‖‖P_n‖，即 √(2n + 1) ≤ K‖S‖ 对所有 n 成立——不可能。左下图琥珀虚线就是任何逆都必须超过的下界。
  5. 有限环（页面数值）。右下图把同一个生成元放到 N 个格点的环上：q = 0 块有精确的 0，其他本征值随 q → 0 靠近 0。这是有限体积的另一个算子，只作直观对照。

原文：问题卷宗 · LatticeLindbladianZeroSpectrum.lean · Blueprint · 文献笔记 · Klausen，arXiv:2206.09879v3 · doi:10.48550/arXiv.2206.09879

An infinite chain of sites, with at most one particle per site x; the state of the open quantum system is a kernel ρ(x, y), and its evolution is given by a Lindblad generator t: the Hamiltonian H makes the particle hop coherently, and the jump operators L_k describe the environment. Klausen studies the spectra of such generators and asks: if the range is finite and the generator translation invariant (and the L_k have rank one), must 0 lie in the spectrum? This library proves in Lean that it must, without needing rank one, a self-adjoint H or g > 0.

  1. Why 0. Lindblad evolution preserves the trace, so the full trace sends the output of t to 0: Σ_x (tρ)(x, x) = 0. But the identity kernel (the one behind the trace) is not in ℓ², so this alone does not show that t is not invertible.
  2. Truncate. Cut the trace to |x| ≤ n: P_n is 2n + 1 ones on the diagonal, it lies in ℓ², and its norm is √(2n + 1) (cyan bars in the 3D view, the cyan line in the lower left chart).
  3. Only the boundary is left. Σ_{|x|≤n} (tρ)(x, x) adds up the coefficients used by each (tρ)(x, x) (grey bars). Inside, they cancel, because the full trace sends every matrix unit to 0; only a few coefficients near (±n, ±n) survive (magenta bars), all inside the amber region given by the Lean proof. Their norm does not grow with n (the magenta line in the lower left chart).
  4. No inverse. If t had an inverse S, put ρ = SP_n: then ‖P_n‖² = ⟨P_n, tρ⟩ ≤ K‖S‖‖P_n‖, so √(2n + 1) ≤ K‖S‖ for every n — impossible. The amber dashed line in the lower left chart is the lower bound every inverse would have to exceed.
  5. A finite ring (page numbers). The lower right chart puts the same generator on a ring of N sites: the q = 0 block has an exact 0, and the other eigenvalues approach 0 as q → 0. This is a different, finite-volume operator, shown only for intuition.
