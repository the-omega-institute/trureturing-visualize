阶乘之比 (6n)!/((3n)!(2n)!) 这类数是不是整数，是一个古老的问题。Bala 把其中一些分母或分子换成分数阶乘 x! = Γ(1 + x)，例如 (n/2)!、(3n/2)!、(n/3)!，猜想所得的比值仍然对每个 n 都是整数。本库在 Lean 里证明了他的七个猜想。

  1. 七个序列。A347854 = (6n)!(n/2)!/((3n)!(2n)!(3n/2)!)；A347856 = (6n)!(n/2)!/((4n)!n!(3n/2)!)；A347857 = (6n)!(3n/2)!/((3n)!(2n)!(5n/2)!)；A347858 = (9n)!(n/2)!/((3n)!(2n)!(9n/2)!)；A347855 = (4n)!(n/3)!/((2n)!n!(4n/3)!)；以及 a(3n + 1) = 3³ⁿ⁺¹·b(n)、a(3n + 2) = 3³ⁿ⁺²·c(n) 里的辅助序列 b、c。七个都已冻结。
  2. 分数阶乘怎么变成有理数。n 为偶数时 (n/2)! 就是普通阶乘。n 为奇数时 Γ(k + ½) = (2k)!·√π/(4ᵏ·k!)，同一个比值里分子分母各有一个 √π，相消后剩下有理数，并带出一个 2 的幂。三分之一处用 Γ(1 + x)/Γ(1 + x + n) = 1/∏(x + j)，得到 3ⁿ/∏ⱼ₌₁ⁿ (n + 3j)。页面就这样精确算出每一项。
  3. Legendre 公式与阶梯。素数 p 在 m! 里的次数是 Σₑ ⌊m/pᵉ⌋。对奇素数 p，半整数阶乘的次数换成 Σₑ ⌊(m/pᵉ + 1)/2⌋（数 1 到 m 中的奇数里 pᵉ 的倍数）。于是 vₚ(a(n)) = Σₑ L(n/pᵉ)，其中 L 是由向下取整拼成的阶梯函数，n 为偶数与奇数各一条。页面在一个周期 [0, 2) 的每个断点区间上算出 L：四个半整数序列的两条阶梯都只取 0 和 1。所以每个素数幂贡献 0 或 1，vₚ(a(n)) ≥ 0。
  4. p = 2 与 p = 3。p = 2 在奇数 n 处来自 Γ 的那一项单独计算，卷宗说明奇数 n 时 A347854、A347856、A347857 带有 2²ⁿ，A347858 带有 2⁸ⁿ；A347855 在 3 ∤ n 时带有 3ⁿ，Lean 里的中间结论 third_dvd 给出其余部分的整除性。
  5. 与文献的关系。Blanco Gómez（Zenodo，2026）先于本库发表了这些整除性的证明；本库的 Lean 证明是独立的形式化。偶数项 A347854(2m) = u(m) 是 Vasyunin 的零散序列之一，Bober（2009）用阶梯函数研究了这一类比值。
  6. 边界。OEIS 条目里的超同余与代数性问题仍然开放。

Whether ratios such as (6n)!/((3n)!(2n)!) are integers is an old question. Bala replaced some of the factorials by fractional ones, x! = Γ(1 + x), such as (n/2)!, (3n/2)! and (n/3)!, and conjectured that the ratios are still integers for every n. This library proves his seven conjectures in Lean.

  1. The seven sequences. A347854 = (6n)!(n/2)!/((3n)!(2n)!(3n/2)!); A347856 = (6n)!(n/2)!/((4n)!n!(3n/2)!); A347857 = (6n)!(3n/2)!/((3n)!(2n)!(5n/2)!); A347858 = (9n)!(n/2)!/((3n)!(2n)!(9n/2)!); A347855 = (4n)!(n/3)!/((2n)!n!(4n/3)!); and the auxiliaries b, c in a(3n + 1) = 3³ⁿ⁺¹·b(n), a(3n + 2) = 3³ⁿ⁺²·c(n). All seven are frozen.
  2. How fractional factorials become rationals. For even n, (n/2)! is an ordinary factorial. For odd n, Γ(k + ½) = (2k)!·√π/(4ᵏ·k!), and in each ratio one √π above cancels one below, leaving a rational with a power of 2. At thirds, Γ(1 + x)/Γ(1 + x + n) = 1/∏(x + j) gives 3ⁿ/∏ⱼ₌₁ⁿ (n + 3j). The page computes every term exactly this way.
  3. Legendre’s formula and the staircases. The exponent of a prime p in m! is Σₑ ⌊m/pᵉ⌋. For an odd prime, the exponent in a half-integer factorial becomes Σₑ ⌊(m/pᵉ + 1)/2⌋ (counting the multiples of pᵉ among the odd numbers up to m). So vₚ(a(n)) = Σₑ L(n/pᵉ), where L is a step function made of floors, one for even n and one for odd n. The page evaluates L on every breakpoint interval of a period [0, 2): both staircases of all four half-index sequences take only the values 0 and 1. So each prime power contributes 0 or 1, and vₚ(a(n)) ≥ 0.
  4. p = 2 and p = 3. For p = 2 at odd n, the term from the Gamma function is counted separately; the dossier shows that at odd n A347854, A347856 and A347857 carry 2²ⁿ and A347858 carries 2⁸ⁿ, and that A347855 carries 3ⁿ for 3 ∤ n, while the intermediate Lean result third_dvd gives divisibility of the rest.
  5. Relation to the literature. Blanco Gómez (Zenodo, 2026) published proofs of these integrality statements before this library; the Lean proofs here are an independent formalization. The even terms A347854(2m) = u(m) form one of Vasyunin’s sporadic sequences, and Bober (2009) studied this class of ratios through their step functions.
  6. Limits. The supercongruences and algebraicity questions in the OEIS entries remain open.
