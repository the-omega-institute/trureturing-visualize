三个小博弈，各有一个作者在论文里留下的问题。本库把三个问题都结算了：两个猜想得到证明，一个被反例推翻。页面把三个博弈都现算出来，第三个还可以亲手下。

  1. Divisor Nim（已冻结）。局面是若干堆石子。一步选一堆 h，从中取走 d 颗（1 ≤ d ≤ h），条件是 d 整除其余每一堆；取空的堆就消失。只剩一堆时什么都能取，所以单独一堆 n 的 Grundy 值就是 n。Tyagi（2026）证明 g ≤ 2hmin + ⌊log₂ hmin⌋，并猜想对数项可以去掉；本库证明了 g ≤ 2hmin，对任意多堆、任意大小都成立。证明的第一步是必败局面的刻画：取各堆 2-adic 阶的最小值 k，g = 0 当且仅当阶恰为 k 的堆有偶数个。页面画出两堆或三堆的 Grundy 表；在页面搜索的范围里，{1, 4, 10} 这类局面恰好取到 2hmin。
  2. 随机减法游戏（已冻结）。给定减法集 S，局面是一个数 n。轮到的人在 {s ∈ S : s ≤ n} 里均匀随机挑一个减掉，无步可走者输。轮到的人的获胜概率满足 an = 1 − 平均 an−s。Capitelli 与 Somma（2024）证明 S 含偶数（且最大公因数为 1）时 an 收敛，并猜想 S 全为奇数时不收敛。本库的证明：令 bn = (−1)n(1 − 2an)、dn = bn + bn+1，则 dn ≥ 0，并且窗口和 JN = Σs∈S Σ0≤r<s dN−s+r 从 N = max S 起保持不变、至少为 2。如果 an 收敛，dn 就会趋于 0，窗口和也会趋于 0，矛盾。卷宗还指出这个论证不需要最大公因数的条件。
  3. 二染色博弈（已冻结）。两人轮流给树的顶点贴标签：Admirable 先手、只贴 0，Impish 只贴 1。边的标签是两端之和模 2，终局时的差 d = |e₁ − e₀| 就是比分；Admirable 想让它小，Impish 想让它大。双方最优时的比分记作 cg。Krop、Mittal、Wigal（2024）猜想任何 n 阶树都满足 cg(T) ≤ cg(Pn)。反例是十个顶点的树：路径 0–1–…–7，再在 0 上挂 8 和 9。Impish 把顶点配成 (0, 4)、(1, 5)、(2, 6)、(3, 7)、(8, 9)，对手下一个他就下配对的另一个，这样终局差至少 3；而 P₁₀ 上 Admirable 有策略把差压在 1 以内（九条边，差是奇数，所以恰好是 1）。页面用极小极大搜索算出精确值，你可以在图上替任何一方落子，剩下的由双方最优续下。
  4. 边界。页面上的 Grundy 表、概率序列和博弈值都是有限范围内现算的数；冻结的是上面三条对一切局面成立的定理。

Three small games, each with a question its authors left open in their paper. This library settles all three: two conjectures are proved and one is refuted by a counterexample. The page computes all three games, and you can play the third one yourself.

  1. Divisor Nim (frozen). A position is a collection of heaps. A move picks a heap h and takes d stones from it (1 ≤ d ≤ h), provided d divides every other heap; a heap emptied disappears. With a single heap anything may be taken, so a single heap n has Grundy value n. Tyagi (2026) proved g ≤ 2hmin + ⌊log₂ hmin⌋ and conjectured that the logarithmic term can be dropped; this library proves g ≤ 2hmin for any number of heaps of any size. The first step of the proof describes the losing positions: with k the least 2-adic valuation of the heaps, g = 0 exactly when an even number of heaps have valuation k. The page draws Grundy tables for two or three heaps; within the range the page searches, positions such as {1, 4, 10} attain 2hmin exactly.
  2. Random subtraction games (frozen). Given a subtraction set S, a position is a number n. The player to move subtracts an element of {s ∈ S : s ≤ n} chosen uniformly at random, and a player with no move loses. The winning probability of the player to move satisfies an = 1 − the average of an−s. Capitelli and Somma (2024) proved that an converges when S contains an even number (and has gcd 1), and conjectured that it does not converge when every element of S is odd. The proof in this library: put bn = (−1)n(1 − 2an) and dn = bn + bn+1; then dn ≥ 0, and the window sum JN = Σs∈S Σ0≤r<s dN−s+r stays constant from N = max S on and is at least 2. If an converged, dn would tend to 0 and so would the window sum, a contradiction. The dossier notes that this argument does not need the gcd condition.
  3. The cordiality game (frozen). Two players take turns labelling the vertices of a tree: Admirable moves first and only writes 0, Impish only writes 1. An edge is labelled by the sum of its ends mod 2, and the final discrepancy d = |e₁ − e₀| is the score; Admirable wants it small and Impish wants it large. The score under optimal play is cg. Krop, Mittal and Wigal (2024) conjectured that every tree of order n has cg(T) ≤ cg(Pn). The counterexample is a tree on ten vertices: the path 0–1–…–7 with 8 and 9 hanging from 0. Impish pairs the vertices as (0, 4), (1, 5), (2, 6), (3, 7), (8, 9) and answers every move with its partner, which forces a final discrepancy of at least 3; on P₁₀, Admirable has a strategy keeping it at most 1 (nine edges make it odd, so exactly 1). The page computes exact values by minimax search; you can play a move for either side on the graph, and the rest continues with optimal play.
  4. Limits. The Grundy tables, probability sequences and game values on the page are numbers computed over finite ranges; what is frozen are the three theorems above, which hold for all positions.
