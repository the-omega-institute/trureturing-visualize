    中间的光球是一个量子比特系统。环境里的量子比特一个接一个飞过它，每一个都带走一份关于系统某个量的副本，然后向外散开。外圈的观察者各自只读一小片互不重叠的碎片。时间轴就是已经写入的记录份数。

    1. 三层经典性（OBSERVER-QUANTUM 第 5 节，GICT 定理 6.26）。理论卷把经典世界的涌现分成三层：中心层是强制的；指针基层由记录规则选定——账本就是环境，记账就是退相干；冗余层是量子达尔文主义——账本的任何一小片都载有几乎完整的经典事实，互不相识的观察者读各自的碎片就会一致。理论卷自己声明：后两层是对特定记账通道的条件定理。本页演示的就是这样一个具体通道。
    2. 模型。系统态 |ψ⟩ 的指针概率为 p。第 k 份记录把系统写成 |0⟩|e0⟩ + |1⟩|e1⟩ 的形式，两份记录态的重叠为 c。n 份之后整体是纯态 √p|0⟩|A⟩ + √(1−p)|1⟩|B⟩，⟨A|B⟩ = cn。系统、任一碎片和其余部分的熵都由两个非正交纯态的混合给出，所以互信息 I(S:F) = S(S) + S(F) − S(SF) 有闭式解，页面逐点精确计算。
    3. 达尔文平台。c = 0 时，任何不完整的碎片都恰好给出 I(S:F) = H(p)：一小片就带着全部经典信息，再多也不会增加，直到拿到整个环境，才跳到 2H(p)（其中多出的 H(p) 是量子关联）。这两端都有冻结定理：orthogonal_record_trace_gives_sbs_consensus（正交记录下碎片的互信息恰为 H(p)）与 coherent_copy_correlation_tax（相干复制的关联 = 记录熵 + 被摧毁的相干，纯态时为 2H）。c > 0 时，要攒够更多份才爬上平台。冗余度 Rδ 是“能各自得到 (1−δ)H 的互不重叠碎片数”，页面取 δ = 0.1。
    4. 指针基由记录规则选定。换一种记录规则（例如记 X 而不是 Z），被保留下来的就是另一组坐标里的对角矩阵：phase_damping_in_basis_fixed_iff、fourier_phase_damping_fixed_iff。系统的布洛赫矢量向指针轴塌缩，垂直分量按 cn 衰减：repeated_record_exponential_decay、trace_environment_controlled_record_eq_phase_damping。
    5. 单配锁：每份账本一种经典。碎片猜中指针值的最优成功率为 ½(1 + √(1 − 4p(1−p)c2m))，一小片就足够；而任何碎片与系统相位（互补量）的关联至多 2√(p(1−p))·cn−m，只有几乎拿到整个环境才不为零。所以互补的那种“经典”在数学上合法，却被锁死，无法被冗余登记。理论卷给出的是这一结论及其数值证书；本页的两个公式是对这个模型的直接计算，不是 Lean 定理。
    6. 观察者。每位观察者用对称的最优测量读自己的碎片，读对的概率是 ½(1 + √(1 − c2m))，条件于分支彼此独立。页面用固定种子抽出这次运行的事实和每个人的读数，所以只改观察者的问题或视角不会改变这次运行。问相位时，每人猜中的概率只有 ½(1 + 关联)，彼此不再一致。
    7. 模型边界。系统是单个量子比特，环境是逐份写入的独立量子比特，记录重叠 c 对每份相同，观察者的读法是示意的对称测量。它不是某个真实系统的数值模拟；理论卷里的平台与单配数值证书对应的具体通道未必与本页参数相同。

    The glowing orb in the middle is a one-qubit system. Environment qubits fly past it one after another, each carrying off a copy of one of the system’s quantities before drifting outward. The observers on the outer ring each read only a small fragment, and no two fragments overlap. The time axis is simply the number of records written so far.

    1. Three layers of classicality (OBSERVER-QUANTUM section 5, GICT Theorem 6.26, both in Chinese). The theory volume splits the emergence of the classical world into three layers. The central layer is forced. The pointer layer is selected by the record rule: the ledger is the environment, and keeping the ledger is decoherence. The redundancy layer is quantum Darwinism: any small piece of the ledger carries almost the whole classical fact, and observers who never meet agree by reading their own fragments. The volume itself states that the last two layers are conditional theorems for a specific record channel. This page shows one such concrete channel.
    2. The model. The system state |ψ⟩ has pointer probability p. The k-th record writes the system as |0⟩|e0⟩ + |1⟩|e1⟩, where the two record states overlap by c. After n records the whole is the pure state √p|0⟩|A⟩ + √(1−p)|1⟩|B⟩ with ⟨A|B⟩ = cn. The entropies of the system, of any fragment and of the rest all come from mixtures of two non-orthogonal pure states, so the mutual information I(S:F) = S(S) + S(F) − S(SF) has a closed form, which the page evaluates exactly at every point.
    3. The Darwin plateau. With c = 0 every incomplete fragment gives exactly I(S:F) = H(p): one small piece carries all the classical information, and more pieces add nothing until the whole environment is taken, when it jumps to 2H(p) (the extra H(p) is quantum correlation). Both ends are frozen theorems: orthogonal_record_trace_gives_sbs_consensus (with orthogonal records a fragment’s mutual information is exactly H(p)) and coherent_copy_correlation_tax (a coherent copy’s correlation equals the record entropy plus the destroyed coherence, 2H for a pure state). With c > 0 more records are needed to climb onto the plateau. The redundancy Rδ is the number of disjoint fragments that each obtain (1−δ)H; the page uses δ = 0.1.
    4. The record rule selects the pointer basis. With a different record rule (for example recording X instead of Z), the matrices that survive are diagonal in other coordinates: phase_damping_in_basis_fixed_iff, fourier_phase_damping_fixed_iff. The system’s Bloch vector collapses onto the pointer axis, and its perpendicular part decays as cn: repeated_record_exponential_decay, trace_environment_controlled_record_eq_phase_damping.
    5. The monogamy lock: one classical world per ledger. A fragment guesses the pointer value with optimal success ½(1 + √(1 − 4p(1−p)c2m)), so a small piece is enough; but the correlation of any fragment with the system’s phase (the complementary quantity) is at most 2√(p(1−p))·cn−m, which is non-zero only when the fragment is almost the whole environment. The complementary kind of “classical” is mathematically legitimate but locked, and cannot be recorded redundantly. The theory volume states this conclusion with numerical certificates; the two formulas here are direct calculations for this model, not Lean theorems.
    6. The observers. Each observer reads their fragment with the symmetric optimal measurement, which is right with probability ½(1 + √(1 − c2m)), independently given the branch. The page draws this run’s fact and every reading from fixed seeds, so changing only the observers’ question or the view does not change the run. When they ask about the phase, each guesses right only with probability ½(1 + correlation), and they stop agreeing.
    7. Model limits. The system is a single qubit, the environment consists of independent qubits written one at a time, every record has the same overlap c, and the observers’ readout is a schematic symmetric measurement. This is not a numerical simulation of any real system, and the specific channel behind the theory volume’s plateau and monogamy certificates need not use this page’s parameters.
