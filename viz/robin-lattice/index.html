理论接口 · 这个页面在演示什么Theory interface · what this page shows

整数 n = ∏ pap 是素数指数格上的一个点，乘以素数 p 是一条边。记 Z(n) = σ(n)/n = ∏ Sp(ap)，Sp(a) = 1 + 1/p + … + 1/pa，Robin 容量 eγ log log n，余量 M(n) = eγ log log n − Z(n)，对数余量 C(n) = log(eγ log log n / Z(n))。Robin 判据说：黎曼猜想成立 ⇔ 全部 n > 5040 都有 M(n) > 0。页面给每个点着上“证据的颜色”，然后研究哪些证书能覆盖整条边、整条纤维乃至无限区域。

  1. 格点与 κ 纤维（理论卷）。AURIC 投影把 (a2, a3, a5, a7) 送到 (U, V, W) = (a2 + a7, a3, a5 + a7)。7 在投影里是 2 方向与 5 方向的对角，因为 7 = 2 + 5；被合并的来源由隐藏坐标 κ = a7 恢复，0 ≤ κ ≤ min(U, W)，同一位置上的整数是 n(κ) = 2U3V5W·(7/10)κ。例如 (4, 3, 2) 上的 10800、7560、5292 投影重合，余量却分别约为 0.410、0.090、0.811。
  2. 边（已冻结）。沿 n → nq，Z 的倍率是 1 + 1/(q·σ(qa))（a 是 q 在 n 中的指数），尺度的增长是 log log 的增量。边检验 (Z(nm)/Z(n) − 1)·log log n ≤ log(1 + log m / log n) 恰好说 Robin 比值不增，所以把 Robin 不等式从 n 传到 nm（robinAt_mul_of_edgeTest）。它扔掉了 n 处已有的余量，只是充分条件：27440 → 301840 这条边不过检验，但 301840 的比值只有约 0.655。
  3. 素数纤维（已冻结）。同一方向上增量按至少 1/q 的比例缩小，而对数尺度只按调和速度减小；配合 (L + ℓ)(L + 2ℓ) ≤ L2eℓ（L = log n ≥ 3，ℓ = log q），首层检验通过就推出每一层通过（edgeTest_mul_prime_pow），于是整条纤维 n·qk 都满足 Robin（robinAt_mul_prime_pow）。这对每个素数方向成立，不需要 q > 7。
  4. 换素数与压缩（已冻结 + 推导）。固定指数时 Sq(a) ≤ Sp(a)（q ≥ p），而整数变大，所以 Robin 不等式从 pam 传到 qam（robinAt_prime_replace）。把 N 的第 i 小素数换成第 i 个素数得到压缩数 c(N) ≤ N，并有 Z(N) ≤ Z(c(N))。不同素因子不超过 5 个时 c(N) 是十一光滑数：c(N) > 5040 时由 robin_eleven_smooth 加逐个换素数得到 N 的证书（青色）；c(N) ≤ 5040 时由冻结的 5040 最优定理得 Z(N) ≤ 403/105，而 N ≥ 5600 时 eγ log log N > 403/105（这条阈值在页面上是浮点核对，紫色）。
  5. 面（推导，未形式化）。两个不同素数的 Euler 因子分离，Z(n)Z(npq) = Z(np)Z(nq)，所以 C 的四角混合差只剩 g = log log 的混合差，g″ < 0 使它为负：每块乘法矩形有一笔确定的“面损失” Ap,q(n)，hk·K(L + h + k) ≤ A ≤ hk·K(L)，K(L) = (log L + 1)/(L2(log L)2)。三个角都安全还不够，余量要付得起这块损失。
  6. 覆盖与前沿。覆盖视图把 (5040, X] 中每个整数按最强的可用证据着色。106 以内，青色与紫色几乎覆盖了不同素因子 ≤ 5 的全部整数；剩下的是不同素因子 ≥ 6 个的整数，它们只能靠边检验（品红）或只有数值（灰）。第 k 个前缀族的饱和常数 Mk = ∏i≤k pi/(pi − 1) 决定它的有限危险范围 log log N < e−γMk；Mertens 给出 Mk ~ eγ log pk，这个范围随 k 无界增长，所以逐族加素数永远不能完成全称命题。按 Nicolas 的准则，“每个范围都包含自己的素数阶乘”恰好等价于黎曼猜想；右图只画数值。
  7. 边界。颜色是证据，不是置信度。浮点数只用于显示、边检验和一条阈值，相应颜色已经标明；页面没有把任何未覆盖的点说成反例，也没有证明全部 n > 5040 的 Robin 不等式。连续松弛（把指数当实数）在 log n ≈ log 6000 附近超过 Robin 上界，这说明光滑插值不能代替整数证书，不是整数反例。黎曼猜想仍是开放问题。

An integer n = ∏ pap is a point of the prime-exponent lattice, and multiplying by a prime p is an edge. Write Z(n) = σ(n)/n = ∏ Sp(ap) with Sp(a) = 1 + 1/p + … + 1/pa, the Robin capacity eγ log log n, the margin M(n) = eγ log log n − Z(n) and the log margin C(n) = log(eγ log log n / Z(n)). Robin’s criterion says the Riemann hypothesis holds if and only if M(n) > 0 for every n > 5040. The page gives every point the colour of its evidence and asks which certificates cover a whole edge, a whole fibre or an infinite region.

  1. The lattice and the κ fibre (theory volume). The AURIC projection sends (a2, a3, a5, a7) to (U, V, W) = (a2 + a7, a3, a5 + a7). In the projection 7 is the diagonal of the 2 and 5 directions, because 7 = 2 + 5; the merged sources are recovered by the hidden coordinate κ = a7 with 0 ≤ κ ≤ min(U, W), and the integers at one position are n(κ) = 2U3V5W·(7/10)κ. For instance 10800, 7560 and 5292 project onto (4, 3, 2), yet their margins are about 0.410, 0.090 and 0.811.
  2. Edges (frozen). Along n → nq the factor of Z is 1 + 1/(q·σ(qa)), where a is the exponent of q in n, while the scale grows by the increment of log log. The edge test (Z(nm)/Z(n) − 1)·log log n ≤ log(1 + log m / log n) says exactly that the Robin ratio does not increase, so it carries Robin’s inequality from n to nm (robinAt_mul_of_edgeTest). It discards the margin already present at n and is only sufficient: the edge 27440 → 301840 fails the test, yet 301840 has ratio about 0.655.
  3. Prime fibres (frozen). Along one direction the excess shrinks by at least a factor 1/q while the logarithmic scale shrinks only harmonically; with (L + ℓ)(L + 2ℓ) ≤ L2eℓ (L = log n ≥ 3, ℓ = log q), a passing first layer forces every later layer to pass (edgeTest_mul_prime_pow), so the whole fibre n·qk satisfies Robin’s inequality (robinAt_mul_prime_pow). This holds in every prime direction; q > 7 is not needed.
  4. Swapping primes and compression (frozen + derived). At a fixed exponent Sq(a) ≤ Sp(a) for q ≥ p while the integer grows, so Robin’s inequality passes from pam to qam (robinAt_prime_replace). Replacing the i-th smallest prime of N by the i-th prime gives the compression c(N) ≤ N with Z(N) ≤ Z(c(N)). With at most five distinct primes c(N) is 11-smooth: if c(N) > 5040, robin_eleven_smooth and one swap per prime certify N (cyan); if c(N) ≤ 5040, the frozen 5040-optimum theorem gives Z(N) ≤ 403/105, and eγ log log N > 403/105 once N ≥ 5600 (this threshold is a floating-point check on the page, violet).
  5. Faces (derived, not formalized). The Euler factors of two different primes separate, Z(n)Z(npq) = Z(np)Z(nq), so the four-corner mixed difference of C is the mixed difference of g = log log alone, and g″ < 0 makes it negative: every multiplication rectangle carries a definite face loss Ap,q(n), with hk·K(L + h + k) ≤ A ≤ hk·K(L) and K(L) = (log L + 1)/(L2(log L)2). Three safe corners are not enough; their margins must pay for this loss.
  6. Coverage and the frontier. The coverage view colours each integer in (5040, X] by the strongest evidence available. Below 106, cyan and violet cover almost every integer with at most five distinct primes; what remains are the integers with six or more distinct primes, reached only by the edge test (magenta) or by numbers alone (grey). The saturation constant Mk = ∏i≤k pi/(pi − 1) of the k-th prefix family fixes its finite danger range log log N < e−γMk; Mertens gives Mk ~ eγ log pk, so this range grows without bound in k, and adding primes family by family can never finish the universal statement. By Nicolas’s criterion, “every range contains its own primorial” is exactly equivalent to the Riemann hypothesis; the side chart draws numbers only.
  7. Limits. A colour is evidence, not confidence. Floating-point numbers are used only for display, for the edge test and for one threshold, and the colours say so; the page calls no uncovered point a counterexample and does not prove Robin’s inequality for all n > 5040. The continuous relaxation (exponents treated as reals) exceeds the Robin bound near log n ≈ log 6000; this shows that smooth interpolation cannot replace integer certificates and is not an integer counterexample. The Riemann hypothesis remains open.
