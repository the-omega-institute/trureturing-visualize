把 n 个非负数排成一圈，比较 (Σ xᵢ)(Σ xᵢᵃ xᵢ₊₁ᵇ) 与 (Σ xᵢᶜ)²，c = (a + b + 1)/2。两边次数相同；全相等时恰好相等。维数小时不等式往往成立，维数大了就会失败。Javaheri 猜想成立的最大维数由一个二阶变分的门槛精确给出：N*(a, b) = max{n : (a + b − 1)² ≤ 8ab sin²(π/n)}。本库在 Lean 里证明这个公式在 (6, 1) 不对。

  1. 门槛（左下图）。品红虚线是 (a + b − 1)²，青点是 8ab sin²(π/n)；点在线上方的 n 满足门槛，最大的就是 N*。(6, 1) 时 n = 3 恰好在线上：36 = 48·(3/4)。
  2. 三元组（三维视图）。把三元组按和归一，就是一个三角形；高度是两边之比减 1 的带符号平方根。顶点处左边为 0，比值最小；中心全相等，比值为 1。品红网格高出零平面的地方，不等式失败。
  3. 冻结的反例。(6, 5, 5) 在中心附近，比值 1.000056：左边 6482480，右边 6482116，差 364。因为 N* = 3 而 3 维已经失败，猜想不成立。
  4. 数值搜索（右下图，页面数值）。每个维数各做一次 Nelder–Mead 搜索，柱高是找到的最大比值。(6, 1) 时从 n = 3 起全部失败；最坏的三元组比值约 1.0177。
  5. 别的参数（页面数值）。(4, 1) 时门槛同样在 N* = 4 取等号，而四元组 (7, 7, 10, 9) 让 n = 4 失败；(3, ½) 与 (1, 1) 在 n ≤ 7 内数值与猜想一致。拖动 a、b 可以自己找。

原文：问题卷宗 · JavaheriArrangementDimensionRefutation.lean · Blueprint · 文献笔记 · Javaheri，arXiv:2610.33653v1 · doi:10.48550/arXiv.2610.33653

Put n nonnegative numbers on a circle and compare (Σ xᵢ)(Σ xᵢᵃ xᵢ₊₁ᵇ) with (Σ xᵢᶜ)², c = (a + b + 1)/2. Both sides have the same degree, and equal entries give equality. In small dimensions the inequality tends to hold, in large ones it fails. Javaheri conjectured that the largest valid dimension is given exactly by a second-variation threshold: N*(a, b) = max{n : (a + b − 1)² ≤ 8ab sin²(π/n)}. This library proves in Lean that the formula is wrong at (6, 1).

  1. The threshold (lower left chart). The magenta dashed line is (a + b − 1)², the cyan points are 8ab sin²(π/n); the n whose point lies on or above the line satisfy the threshold, and the largest one is N*. At (6, 1), n = 3 sits exactly on the line: 36 = 48·(3/4).
  2. Triples (3D view). Scaling a triple to sum 1 gives a triangle; the height is the signed square root of the ratio of the two sides minus 1. At the vertices the left side is 0 and the ratio is smallest; at the centre all entries are equal and the ratio is 1. Where the magenta mesh rises above the zero plane, the inequality fails.
  3. The frozen counterexample. (6, 5, 5) lies near the centre with ratio 1.000056: left 6482480, right 6482116, difference 364. Since N* = 3 while dimension 3 already fails, the conjecture is false.
  4. The numerical search (lower right chart, page numbers). A Nelder–Mead search runs in every dimension, and each bar is the largest ratio found. At (6, 1) every dimension from 3 on fails; the worst triple has ratio about 1.0177.
  5. Other parameters (page numbers). At (4, 1) the threshold also holds with equality, at N* = 4, yet the quadruple (7, 7, 10, 9) breaks n = 4; (3, ½) and (1, 1) agree with the conjecture for n ≤ 7. Drag a and b to explore.
