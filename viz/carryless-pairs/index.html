无进位乘法把二进制数当作 GF(2) 上的多项式相乘：竖式里每一列只取奇偶，不进位。方程 m·k = C(u, k) 问：哪些 k 的普通 m 倍恰好等于它与 u 的无进位乘积。Karttunen 在 OEIS 里收集了这样的集合，并猜想某些集合相等或互相包含，只做了有限的检查。本库在 Lean 里对全部 k 证明了四条。

  1. 从低位读 k。两种乘法都可以一位一位地从低位算起：普通乘法要记住进位 c，无进位乘法要记住还没对齐的异或部分 d。状态 (c, d) 就是“剩下的位还欠多少”，读一位就转到下一个状态；对不上就拒绝。
  2. 状态是有限的。c 与 d 都不会无限增长，所以两条方程的状态对只有有限个。三维视图就是这个乘积自动机：从 (0, 0)|(0, 0) 出发，每个节点两条出边（读 0 或读 1）。
  3. 证明就是检查每个节点。相等的情形：每个可达节点上，两条方程“此刻结束是否成立”都相同（琥珀 = 都成立）。包含的情形：没有节点只让第一条成立（紫色节点只让第二条成立）。Lean 用 decide 列举这个有限集合，再对 k 归纳。
  4. 沿路径读一个 k。时间轴扫过 k；琥珀线是当前 k 的路径，终点决定两条方程是否成立。右下图把两种乘积逐位对齐，品红位就是它们不同的地方。
  5. 反方向。k = 15 满足 11k = C(31, k) 却不满足 13k = C(29, k)，所以 A115805 ⊆ A115803 是严格的包含。这是页面的计算。

Carryless multiplication multiplies binary numbers as polynomials over GF(2): every column of the long multiplication keeps only its parity and nothing is carried. The equation m·k = C(u, k) asks for which k the ordinary product m·k equals the carryless product of u and k. Karttunen collected such sets in the OEIS and conjectured, after finite checks, that some of them coincide or contain one another. This library proves four of them in Lean for every k.

  1. Read k from the lowest bit. Both products can be computed one bit at a time from the bottom: ordinary multiplication carries c, carryless multiplication keeps the pending exclusive-or part d. A state (c, d) is “what the remaining bits still owe”; reading a bit moves to the next state, and a mismatch rejects.
  2. Finitely many states. Neither c nor d grows without bound, so the two equations have only finitely many state pairs. The 3D view is this product automaton: it starts at (0, 0)|(0, 0), and each node has two outgoing edges (read 0 or read 1).
  3. The proof checks every node. For equality, at every reachable node the two equations agree on whether they would hold if the input ended there (amber = both hold). For containment, no node lets only the first equation hold (violet nodes let only the second). Lean enumerates this finite set by decide and then inducts on k.
  4. Walk one k along its path. The time axis sweeps k; the amber line is the path of the current k, and its end decides both equations. The lower right chart lines the two products up bit by bit, and the magenta bits are where they differ.
  5. The converse. k = 15 satisfies 11k = C(31, k) but not 13k = C(29, k), so A115805 ⊆ A115803 is a strict containment. This is a computation on the page.
