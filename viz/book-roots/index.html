LEAN ✓书图 B_n 的顶点是 Fin (2n + 2)：公共边是 0–1，第 i 页是 0–1–(2i + 2)–(2i + 3)–0（bookGraph）。支配多项式 D(G, X) = Σ X^{|S|}，对所有支配集 S 求和（dominationPolynomial）。FourRealRoots p a b：0 是二重根，a、b 是不同的单根，且没有别的实根。猜想 claim：对每个 n ≥ 1，n 偶时有 a < −2、−1/2 < b < 0 使 FourRealRoots 成立；n 奇时有两个都在 (−1/2, 0) 里的 a、b。本库证明 ¬claim。已冻结：The book B_n has vertices Fin (2n + 2): the shared edge is 0–1 and page i is 0–1–(2i + 2)–(2i + 3)–0 (bookGraph). The domination polynomial D(G, X) = Σ X^{|S|} sums over all dominating sets S (dominationPolynomial). FourRealRoots p a b: 0 is a double root, a and b are distinct simple roots, and there is no other real root. The conjecture, claim: for every n ≥ 1, for even n there are a < −2 and −1/2 < b < 0 with FourRealRoots, and for odd n two such a, b both in (−1/2, 0). This library proves ¬claim. ARGUED本页的论证（未形式化、未经评审）：按 0、1 是否在支配集里分四种情形——都在：每页任取，x²(1 + x)²ⁿ；恰一个在：每页非空，各 x(x² + 2x)ⁿ；都不在：每页非空，且至少一页含 2i + 2、至少一页含 2i + 3，(x² + 2x)ⁿ − 2xⁿ。合起来 D(B_n, x) = x²(1 + x)²ⁿ + (2x + 1)(x² + 2x)ⁿ − 2xⁿ。页面用它算 n > 8，并在 n ≤ 8 与枚举逐项核对。文献里已有书图的支配多项式公式，页面没有逐字比对。The page’s argument (not formalized, not reviewed): split on whether 0 and 1 are in the dominating set — both: each page is free, x²(1 + x)²ⁿ; exactly one: each page nonempty, x(x² + 2x)ⁿ each; neither: each page nonempty, with some page containing 2i + 2 and some containing 2i + 3, (x² + 2x)ⁿ − 2xⁿ. Together D(B_n, x) = x²(1 + x)²ⁿ + (2x + 1)(x² + 2x)ⁿ − 2xⁿ. The page uses it for n > 8 and checks it term by term against enumeration for n ≤ 8. The literature has a formula for book graphs; the page did not compare the two symbol by symbol.
OPEN定理之外：把猜想改成 n ≥ 2 之后是否成立；更紧的区间；所有有限 n 的完整根分类。页面对 n ≤ 20 看到的模式是数值，不是证明。原文的书图公式与命题 5.3（带 n ≥ 2 的条件）不受影响。Outside the theorem: whether the conjecture holds once restricted to n ≥ 2; sharper intervals; a full root classification for every finite n. 图的一个支配集是一组顶点，使每个顶点要么在组里、要么与组里某个点相邻。支配多项式 D(G, x) 的 x^k 系数就是大小为 k 的支配集个数。书图 B_n 把 n 个四边形沿同一条边粘起来，像一本书的 n 页。Rather 猜想 D(B_n, x) 的实根总是很少：偶数 n 是二重根 0、一个比 −2 小、一个在 (−1/2, 0)；奇数 n 是二重根 0 和两个在 (−1/2, 0)。猜想对 n ≥ 1 陈述，而 B₁ 就是四边形。

  1. 反例。四边形 C₄ 的支配集是全部 6 个两点集、4 个三点集与全集，所以 D(C₄, x) = 6x² + 4x³ + x⁴ = x²((x + 2)² + 2)。括号里永远为正，除了 0 没有实根——奇数分支要的两个根不存在。
  2. 三维视图。左边是书：公共边是书脊，每页是一个四边形；高亮的是一个支配集。右边是复平面：D(B_n, x)/x² 的全部根，实轴上两段区间 (−∞, −2) 与 (−1/2, 0) 是猜想放根的地方。
  3. n ≥ 2 呢？页面对 n = 2 … 20 都看到了猜想的模式，但这只是数值；卷宗把改成 n ≥ 2 的版本列为未决。

原文：问题卷宗 · RatherBookRootRefutation.lean · Blueprint · 文献笔记 · doi:10.48550/arXiv.2604.08998 · arXiv:2604.08998

A dominating set of a graph is a set of vertices such that every vertex is in it or adjacent to one of its members. The coefficient of x^k in the domination polynomial D(G, x) counts dominating sets of size k. The book B_n glues n four-cycles along one shared edge, like the n pages of a book. Rather conjectured that D(B_n, x) always has few real roots: for even n a double root at 0, one root below −2 and one in (−1/2, 0); for odd n a double root at 0 and two roots in (−1/2, 0). The conjecture is stated for n ≥ 1, and B₁ is the four-cycle.

  1. The counterexample. The dominating sets of the four-cycle C₄ are its 6 pairs, 4 triples and the whole vertex set, so D(C₄, x) = 6x² + 4x³ + x⁴ = x²((x + 2)² + 2). The bracket is always positive, so there is no real root other than 0 — the two roots the odd branch promises do not exist.
  2. 3D view. On the left is the book: the shared edge is the spine and every page is a four-cycle; the highlighted vertices form a dominating set. On the right is the complex plane with all roots of D(B_n, x)/x²; the two stretches (−∞, −2) and (−1/2, 0) of the real axis are where the conjecture puts its roots.
  3. And n ≥ 2? The page sees the conjectured pattern for n = 2 … 20, but only numerically; the dossier lists the version restricted to n ≥ 2 as open.
