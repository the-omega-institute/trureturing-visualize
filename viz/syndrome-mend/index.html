理论接口 · 这个页面在演示什么Theory interface · what this page shows

一个逻辑量子比特 α|0⟩ + β|1⟩ 被写成三个物理比特 α|000⟩ + β|111⟩（三比特重复码）。8 维空间分成四个两两正交的 2 维层：最上面是编码空间 {|000⟩, |111⟩}；下面三层是翻转第 1、2、3 个比特后的副本，例如 {|100⟩, |011⟩}。两个奇偶校验 Z1Z2、Z2Z3 的结果（综合征）正好说出态在哪一层。每层中央的小球是那一层里逻辑比特的布洛赫矢量，层的亮度是落在这一层的概率。

  1. 正交错误副本（理论卷 ST27.1）。记 Sj = Xj·Enc（S0 = Enc），它们满足 Si†Sj = δijI：每一层都是逻辑信息的一份正交副本。这不是复制了未知态——一次实际状态只占一个联合编码。
  2. 不读也能精确恢复（定理 ST27.2）。噪声 𝒩σ(ρ) = ΣjkσjkSjρSk† 可以是概率混合（σ 对角），也可以是“没翻、翻 1、翻 2、翻 3”的相干叠加（σ 有非对角元）。折回解码 𝒟(X) = ΣjSj†XSj 不读取 σ，也不要求它对角，都给出 tr(σ)ρ = ρ。矩阵恒等式已冻结：orthogonal_syndrome_recovery；把它写成真正的 CPTP 解码通道也已冻结：full_syndrome_decoder。
  3. 漏出 ≠ 丢失（例 ST27.3）。“翻第 1 个比特”确定发生时，整个态都离开了编码空间（相对旧投影的漏出 λ = 1），恢复误差却是 0。能否恢复取决于你被允许访问哪些输出自由度。
  4. Knill–Laflamme 条件（命题 ST28.1；Knill、Laflamme，Phys. Rev. A 55, 900 (1997)）。噪声的 Kraus 算子 Ea 能被精确倒回，当且仅当每一对都满足 Ea†Ec = cacI。必要性已冻结：left_inverse_error_products；充分性已冻结：scalar_products_construct_left_inverse；只要任何恢复存在，仓库里显式算出的谱恢复就是精确的：computed_recovery_of_kraus_left_inverse。“每个比特独立翻转”时，X1X2 与 X3 落在同一层，但 (X3Enc)†(X1X2Enc) 是逻辑翻转 X 而不是 I 的倍数：条件不成立，没有任何恢复能完全倒回。重复码把逻辑错误率从 p 压到 3p² − 2p³（p < 1/2 时更小），这是教科书里的标准计算；重复结构正是 Shor 码（Phys. Rev. A 52, R2493 (1995)）的内层。
  5. 路径扭转（定理 ST29.1、命题 ST29.2）。若第 j 个分支沿途还带回一个已知的逻辑酉 Vj（页面里取相位 Vj = diag(zj, 1)），副本 SjVj 仍两两正交（已冻结：syndrome_transport_orthogonal），知道扭转的解码器仍精确。但若用旧解码 Sj† 折回、又把分支信息丢了，就只剩混合 ΣjpjVjρVj†。
  6. 记录不全时的最优误差（定理 ST30.2 至例 ST30.5）。页面的流水线是：读出一个可能不完整的经典记录 r（条件概率 T(r|j)），用旧解码折回（删掉综合征的量子自由度），再按 r 补偿相位。记 cr = ΣjpjT(r|j)zj、sT = Σr|cr|，所有恢复中最好的半钻石距离误差恰为 e* = (1 − sT)/2，按 cr 的相位补偿即可达到；记录被粗化只会让 e* 变大（推论 ST30.4）；两个相反相位各占一半时，一个记录比特决定误差是 0 还是 1/2（例 ST30.5）。这些是理论卷里的论文证明与本页的模型计算，没有形式化为 Lean 定理。相关的既有研究：环境辅助纠错（Trendelkamp-Schroer、Helm、Strunz，Phys. Rev. A 84, 062314 (2011)），近似纠错的一般条件（Bény、Oreshkov，Phys. Rev. Lett. 104, 120501 (2010)）。
  7. 相位分箱与模型边界（定理 ST31.1）。记录只保存相位落在 K 个等宽箱中的哪一个时，e* ≤ (1 − cos(π/K))/2 ≤ π²/(4K²)。页面的箱从 0° 起等分。门与测量都是理想、瞬时的；平均保真度用 F̄ = (2Fe + 1)/3 由纠缠保真度换算。独立翻转模式下，补偿仍按各层的相位做，e* 公式不再适用，页面只显示这条流水线实际达到的保真度。单次运行用固定种子抽出发生的分支和留下的记录。

原文：量子现实 ST27–ST31 · OrthogonalSyndromeDecoding.lean · OrthogonalSyndromeChannel.lean · KrausLeftInverseNecessity.lean · FiniteKrausReversibility.lean · SpectralRecoveryCorrectness.lean

One logical qubit α|0⟩ + β|1⟩ is written into three physical qubits as α|000⟩ + β|111⟩ (the three-qubit repetition code). The 8-dimensional space splits into four mutually orthogonal 2-dimensional layers: on top the code space {|000⟩, |111⟩}; below it the copies after qubit 1, 2 or 3 flips, for example {|100⟩, |011⟩}. The outcomes of the two parity checks Z1Z2 and Z2Z3 (the syndrome) say exactly which layer the state is in. The small sphere in each layer is the Bloch vector of the logical qubit inside that layer; the brightness of a layer is the probability of being in it.

  1. Orthogonal error copies (theory volume ST27.1). Write Sj = Xj·Enc (S0 = Enc). They satisfy Si†Sj = δijI: every layer is an orthogonal copy of the logical information. The unknown state is not cloned; a single actual state occupies one joint encoding.
  2. Exact recovery without reading anything (Theorem ST27.2). The noise 𝒩σ(ρ) = ΣjkσjkSjρSk† may be a probabilistic mixture (σ diagonal) or a coherent superposition of “no flip, flip 1, flip 2, flip 3” (σ with off-diagonal entries). The fold-back decoder 𝒟(X) = ΣjSj†XSj never reads σ and does not need it to be diagonal; it always returns tr(σ)ρ = ρ. The matrix identity is frozen: orthogonal_syndrome_recovery; writing it as an honest CPTP decoding channel is frozen too: full_syndrome_decoder.
  3. Leakage is not loss (Example ST27.3). When “flip qubit 1” happens with certainty, the whole state leaves the code space (leakage λ = 1 relative to the old projection), yet the recovery error is 0. Whether you can recover depends on which output degrees of freedom you are allowed to access.
  4. The Knill–Laflamme condition (Proposition ST28.1; Knill and Laflamme, Phys. Rev. A 55, 900 (1997)). Noise with Kraus operators Ea can be undone exactly if and only if every pair satisfies Ea†Ec = cacI. Necessity is frozen: left_inverse_error_products; sufficiency is frozen: scalar_products_construct_left_inverse; and whenever any recovery exists, the explicitly computed spectral recovery in the repository is exact: computed_recovery_of_kraus_left_inverse. When each qubit flips independently, X1X2 lands in the same layer as X3, but (X3Enc)†(X1X2Enc) is a logical flip X, not a multiple of I: the condition fails and no recovery can undo the noise exactly. The repetition code lowers the logical error rate from p to 3p² − 2p³ (smaller when p < 1/2), the standard textbook calculation; the same repetition structure is the inner layer of Shor’s code (Phys. Rev. A 52, R2493 (1995)).
  5. Path twists (Theorem ST29.1, Proposition ST29.2). If branch j also brings back a known logical unitary Vj (on this page a phase, Vj = diag(zj, 1)), the copies SjVj are still mutually orthogonal (frozen: syndrome_transport_orthogonal), and a decoder that knows the twists is still exact. But if you fold back with the old decoder Sj† and lose the branch information, only the mixture ΣjpjVjρVj† is left.
  6. The best error with an incomplete record (Theorem ST30.2 to Example ST30.5). The page’s pipeline reads a classical record r that may be incomplete (conditional probabilities T(r|j)), folds back with the old decoder (deleting the quantum degrees of freedom of the syndrome), then undoes the phase according to r. With cr = ΣjpjT(r|j)zj and sT = Σr|cr|, the best half-diamond-distance error over all recoveries is exactly e* = (1 − sT)/2, reached by undoing the phase of cr; coarsening the record can only raise e* (Corollary ST30.4); with two opposite phases at one half each, a single record bit decides whether the error is 0 or 1/2 (Example ST30.5). These are paper proofs in the theory volume and model calculations on this page; they are not formalized as Lean theorems. Related earlier work: environment-assisted error correction (Trendelkamp-Schroer, Helm and Strunz, Phys. Rev. A 84, 062314 (2011)) and general conditions for approximate error correction (Bény and Oreshkov, Phys. Rev. Lett. 104, 120501 (2010)).
  7. Phase bins and model limits (Theorem ST31.1). If the record keeps only which of K equal-width bins the phase falls into, e* ≤ (1 − cos(π/K))/2 ≤ π²/(4K²). The page’s bins split the circle starting at 0°. Gates and measurements are ideal and instantaneous; the average fidelity is converted from the entanglement fidelity by F̄ = (2Fe + 1)/3. In the independent-flip mode the phase is still undone layer by layer; the e* formula no longer applies, and the page shows only the fidelity this pipeline actually reaches. The single run draws the branch that happened and the record left from fixed seeds.
