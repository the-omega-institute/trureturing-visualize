理论接口 · 这个页面在演示什么Theory interface · what this page shows

黎曼 ζ 函数的非平凡零点写成 ρ = ½ + iγ（目前算到的都在临界线 σ = ½ 上）。显式公式是一条等式：一边是对素数幂求和，一边是对零点求和。每个零点贡献一个频率为 γ 的波；把越来越多的波叠起来，素数就从波里显现出来。三维视图里，左边的带子是临界带 0 ≤ σ ≤ 1，零点是线 σ = ½ 上的点，竖线是它在当前公式里的权重；右边每条波是一个零点的贡献，最前面一条是总和（琥珀）与素数一侧（白）。

  1. 素数的台阶（经典，文献）。切比雪夫函数 ψ(x) = Σpk ≤ x log p 在每个素数幂处跳一级。von Mangoldt 证明，x > 1 且不是素数幂时，ψ(x) = x − Σρ xρ/ρ − log 2π − ½ log(1 − x−2)，零点按 |γ| 由小到大求和（J. reine angew. Math. 114, 255 (1895)）。每对 ρ、ρ̄ 贡献 −2Re(xρ/ρ)，振幅约 2√x/γ。页面用前 K 对零点画出右边，看它怎样逼近台阶（跳跃处有 Gibbs 振荡）。
  2. Weil 的形式（已冻结）。取偶的、光滑、紧支撑的检验函数 g，记 ĝ(z) = ∫ g(x) e−izx dx，则 Σρ mρ ĝ(γρ) = ĝ(i/2) + ĝ(−i/2) − Σn Λ(n) n−1/2 (g(log n) + g(−log n)) + (1/2π) ∫ ĝ(t) (Re (Γ′/Γ)(¼ + it/2) − log π) dt，零点和按对称截断 |γ| ≤ T → ∞ 取极限（ClassicExplicitFormula.weil_explicit_formula）。两个收敛前提都已证明，得到无条件版本（UnconditionalExplicitFormula.explicitFormula_unconditional）。公式里的零点数据确实存在，因为 ζ 有无穷多个非平凡零点（ExplicitFormulaObstruction.isNontrivialZero_infinite）。公式本身归功于 Weil（Comm. Sém. Math. Univ. Lund, 1952）。“两边对账”模式用 g(x) = φ(x/L)，φ(u) = e−1/(1−u²)，把三项与零点部分和逐项算出来。
  3. 素数探测器。取 ga(x) = φ((x − a)/ε) + φ((x + a)/ε)：两个宽 ε 的小鼓包放在 ±a。代入冻结的等式，素数项只在 a 靠近某个 log n 时不为零，于是 素数项(a) = 极点项(a) + 阿基米德项(a) − 零点和(a)。右边只用零点和两个光滑项算出来；把它乘以 e·ea/2/2，在 a = log pk 处的峰高约为 log p。零点越多，尖峰越清楚；ε 越小，需要的零点越多。
  4. 正性与黎曼猜想（已冻结的等价）。取平方 g = f ∗ f̃，则 ĝ = |f̂|²，线上的每个零点贡献 |f̂(γ)|² ≥ 0。冻结定理：黎曼猜想成立，当且仅当所有这种平方的素数一侧都 ≥ 0（ExplicitFormulaWeilCriterion.rh_iff_explicitFormulaPositivity）；反过来，只要有一个非实零点离开临界线，就存在一个零点和为负的平方（OffLineNonrealZeroNegativeWeilSquare.offLineNonrealZero_yields_negative_weil_square）。黎曼猜想本身仍未解决。
  5. 离线零点（模型，不是事实）。页面假设第一个零点 γ₁ 离开临界线。由函数方程与共轭对称，它必须成对出现在 ½ ± δ + iγ₁。取 f(x) = x sin(γ₁x) φ(x/L)，这一对的贡献是 4 Re f̂(γ₁ − iδ)²，δ 稍大于 0 就是负数，并且压过其余零点的正贡献。这只是一个假想的零点集合：真实的零点数据里没有这样的零点，页面也只展示这一个检验函数。
  6. 数零点（文献）。N(T) 是 0 < γ ≤ T 的零点个数。von Mangoldt 证明 N(T) = θ(T)/π + 1 + S(T)，其中 θ 是 Riemann–Siegel θ 函数，S(T) = O(log T)（Math. Ann. 60, 1 (1905)）。页面画出 N(T) 与光滑项，以及涨落 S(T)。
  7. 带误差项的素数定理（已冻结）。ψ(x) − x = O(x·exp(−c(log x)1/10))（MediumPNT.MediumPNT）。经典的 de la Vallée Poussin 误差项 exp(−c√log x) 更强，本库没有形式化那一版。
  8. 模型边界。零点数据取自 Odlyzko 的表，前一万个，精确到 3·10−9（zeta_tables）；它们都在线上、都是单零点，这是数值事实（Platt、Trudgian，Bull. London Math. Soc. 53, 792 (2021)），不是本库的定理。页面上的零点和都在第 K 个零点处截断；“两边相差 10−10”是数值读数，定理来自冻结证明。积分用数值求积。

The nontrivial zeros of the Riemann zeta function are written ρ = ½ + iγ (all computed so far lie on the critical line σ = ½). The explicit formula is an identity: a sum over prime powers on one side, a sum over zeros on the other. Each zero contributes a wave of frequency γ; stack more and more waves and the primes emerge from them. In the 3D view the band on the left is the critical strip 0 ≤ σ ≤ 1, zeros are points on the line σ = ½, and each stem is the weight of that zero in the current formula; each wave on the right is the contribution of one zero, and the front line is their sum (amber) against the prime side (white).

  1. The staircase of the primes (classical, literature). The Chebyshev function ψ(x) = Σpk ≤ x log p steps up at every prime power. Von Mangoldt proved that for x > 1 not a prime power, ψ(x) = x − Σρ xρ/ρ − log 2π − ½ log(1 − x−2), the zeros summed in order of |γ| (J. reine angew. Math. 114, 255 (1895)). Each pair ρ, ρ̄ contributes −2Re(xρ/ρ), of amplitude about 2√x/γ. The page draws the right-hand side with the first K pairs and watches it approach the staircase (with Gibbs ripples at the jumps).
  2. Weil’s form (frozen). For an even, smooth, compactly supported test function g, with ĝ(z) = ∫ g(x) e−izx dx, Σρ mρ ĝ(γρ) = ĝ(i/2) + ĝ(−i/2) − Σn Λ(n) n−1/2 (g(log n) + g(−log n)) + (1/2π) ∫ ĝ(t) (Re (Γ′/Γ)(¼ + it/2) − log π) dt, the zero sum taken as the limit of the symmetric cutoff |γ| ≤ T → ∞ (ClassicExplicitFormula.weil_explicit_formula). Both convergence premises are proved, giving the unconditional version (UnconditionalExplicitFormula.explicitFormula_unconditional). The zero data in the formula exists because ζ has infinitely many nontrivial zeros (ExplicitFormulaObstruction.isNontrivialZero_infinite). The formula itself is due to Weil (Comm. Sém. Math. Univ. Lund, 1952). The balance mode uses g(x) = φ(x/L) with φ(u) = e−1/(1−u²) and computes the three terms and the partial zero sums one by one.
  3. A prime detector. Take ga(x) = φ((x − a)/ε) + φ((x + a)/ε): two bumps of width ε placed at ±a. Put it into the frozen identity: the prime term is nonzero only when a is near some log n, so prime term(a) = pole term(a) + archimedean term(a) − zero sum(a). The right-hand side uses only the zero sum and two smooth terms; multiplied by e·ea/2/2, its peak at a = log pk has height about log p. More zeros give sharper spikes; a smaller ε needs more zeros.
  4. Positivity and the Riemann hypothesis (a frozen equivalence). For a square g = f ∗ f̃, ĝ = |f̂|², so every zero on the line contributes |f̂(γ)|² ≥ 0. Frozen theorem: the Riemann hypothesis holds if and only if the prime side of every such square is ≥ 0 (ExplicitFormulaWeilCriterion.rh_iff_explicitFormulaPositivity); conversely, a single nonreal zero off the critical line yields a square with a negative zero sum (OffLineNonrealZeroNegativeWeilSquare.offLineNonrealZero_yields_negative_weil_square). The Riemann hypothesis itself remains unsolved.
  5. An off-line zero (a model, not a fact). The page supposes that the first zero γ₁ leaves the critical line. By the functional equation and conjugate symmetry it must then appear as a pair at ½ ± δ + iγ₁. With f(x) = x sin(γ₁x) φ(x/L), the pair contributes 4 Re f̂(γ₁ − iδ)², which is negative as soon as δ is a little above 0 and outweighs the positive contributions of all other zeros. This is a hypothetical zero set: the real zero data contains no such zero, and the page shows this one test function only.
  6. Counting zeros (literature). N(T) is the number of zeros with 0 < γ ≤ T. Von Mangoldt proved N(T) = θ(T)/π + 1 + S(T), where θ is the Riemann–Siegel theta function and S(T) = O(log T) (Math. Ann. 60, 1 (1905)). The page draws N(T) against the smooth term, and the fluctuation S(T).
  7. The prime number theorem with an error term (frozen). ψ(x) − x = O(x·exp(−c(log x)1/10)) (MediumPNT.MediumPNT). The classical de la Vallée Poussin error term exp(−c√log x) is stronger; this library has not formalized that version.
  8. Model limits. The zero data is the first ten thousand zeros from Odlyzko’s tables, accurate to 3·10−9 (zeta_tables); that they all lie on the line and are simple is a numerical fact (Platt and Trudgian, Bull. London Math. Soc. 53, 792 (2021)), not a theorem of this library. Every zero sum on the page is cut off at the K-th zero; “the two sides differ by 10−10” is a numerical reading, and the theorem comes from the frozen proof. Integrals use numerical quadrature.
