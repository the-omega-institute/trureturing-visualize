理论接口 · 这个页面在演示什么Theory interface · what this page shows

页面上的每个控件都对应 trureturing 理论卷《波粒整体的关系全息表示》里的一条接口。三维体是一次运行的静态历史，不是动画；播放只是移动条件化用的钟读数。

  1. 静态关系体与钟切面（§3）。一次运行写成钟—系统历史态 Γ = WρW†。读钟标签 τ 得到该时刻的切面 ρτ（命题 3.2），NOW 平面就是这个钟条件化。只读钟不会选出走哪条缝（命题 3.3）。
  2. 路径记录与互补（§5.1–5.3）。粒子穿缝时在记录系统留下 dL 或 dR。重叠 κ = ⟨dL|dR⟩ 给出总体条纹可见度 V = |κ|、路径可分辨度 D = √(1−|κ|²)，且 D² + V² = 1。这条等式在 trureturing 中已由 Lean 内核验证并冻结：D5/S3/Quantum/PureState/RecordCoherenceComplementarity.lean。
  3. 擦除与分拣（§5.4）。在旋转基 e± 上读记录，按读数分拣出的两个子系综分别给出条纹与反条纹，相加回到无条纹的总体。屏幕上的总体分布与读取方式无关：改 β、χ 或 N 时落点坐标一个也不动，只有分拣变了，所以不能借此向过去传信号。
  4. 不止两个时空（§4.1、§8.1）。同一份路径记录可以用任何仪器读取：一组满足 Σk Ek = I 的效果，每个读数 k 都给出一个条件时空，它们的联合律 p(x, k) 对 k 求和恒等于未分拣的总体。两结果投影测量只是其中一种；N ≥ 3 时页面用相位协变仪器 mk = (1, ei(χ+2πk/N))/√N，第 k 个时空的条纹相位错开 2πk/N。换一个仪器就换一族分解，总体不变；所以时空的“个数”取决于怎么读记录，不是记录本身携带的。
  5. 读取顺序（§8.2）。顺序概率满足 p(w) = Tr(ρ0Fw)。屏和记录作用在不同子系统上，先读、后读给出同一联合律 p(x, e)。页面沿用同一组随机种子，所以连单个落点和它的标签都不变，档案哈希保持不动。改 κ、φ 才会移动落点；改读取仪器（β、χ、N）只会重新分拣，档案哈希随分拣标签变化。
  6. 两种条件化。LINEAR 只用 τ 之前已读到的记录，未读的运行保持灰色；BLOCK 用整个关系体条件化，包括 τ 之后才读到的记录，所以过去的切面也按分支着色。两者的差别只在条件化用了哪些记录，落点本身没有被改写。
  7. 钟重标（§24）。严格递增的重标只搬运标签，事件信息保持（定理 24.2）。“折叠”重标不是单射，不同时刻被并到同一标签，能恢复什么要另行判断（定理 21.4）。“时间嵌入”滑块在运行钟与实验室钟之间切换，是同一份档案的两种排法。
  8. 模型边界。近轴高斯缝、纵向包络和二维记录空间是示意模型，只保证定性结构和上面的恒等式；它不是某台真实装置的数值模拟。“切换时空”指切换条件化的子系综和时间嵌入。

Every control on this page corresponds to an interface in the trureturing theory volume “Relational holographic representation of the wave–particle whole” (written in Chinese). The 3D block is the static history of one run, not an animation; playing only moves the clock reading used for conditioning.

  1. Static whole and clock slices (§3). One run is written as a clock–system history state Γ = WρW†. Reading the clock label τ gives the slice ρτ at that moment (Proposition 3.2); the NOW plane is this clock conditioning. Reading the clock alone does not select a slit (Proposition 3.3).
  2. Path record and complementarity (§5.1–5.3). Passing the slits leaves dL or dR in a record system. The overlap κ = ⟨dL|dR⟩ gives the overall fringe visibility V = |κ| and the path distinguishability D = √(1−|κ|²), with D² + V² = 1. This identity is kernel-verified and frozen in trureturing: D5/S3/Quantum/PureState/RecordCoherenceComplementarity.lean.
  3. Erasure and sorting (§5.4). Reading the record in a rotated basis e± sorts the hits into two sub-ensembles, one with fringes and one with anti-fringes, which add back to the fringe-free whole. The whole’s distribution on the screen does not depend on how the record is read: changing β, χ or N moves no hit and only re-sorts them, so this cannot send a signal into the past.
  4. More than two spacetimes (§4.1, §8.1). The same path record can be read by any instrument, that is, any set of effects with Σk Ek = I. Each outcome k defines a conditional spacetime, and the joint law p(x, k) summed over k always equals the unsorted whole. A two-outcome projective measurement is one choice; for N ≥ 3 the page uses the phase-covariant instrument mk = (1, ei(χ+2πk/N))/√N, whose k-th spacetime has fringes shifted by 2πk/N. A different instrument gives a different family of decompositions of the same whole, so the number of spacetimes depends on how the record is read, not on the record itself.
  5. Read order (§8.2). Sequential probabilities satisfy p(w) = Tr(ρ0Fw). The screen and the record act on different subsystems, so reading the record first or later gives the same joint law p(x, e). The page reuses the same random seeds, so even single hits and their labels stay the same and the archive hash does not change. Changing κ or φ moves hits; changing the instrument (β, χ, N) only re-sorts them, and the hash follows the new labels.
  6. Two kinds of conditioning. LINEAR uses only records read before τ, so unread runs stay grey. BLOCK conditions on the whole relational block, including records read after τ, so past slices are coloured by branch too. The only difference is which records the conditioning uses; no hit is rewritten.
  7. Clock relabelling (§24). A strictly increasing relabel only moves labels and preserves event information (Theorem 24.2). The “fold” relabel is not injective: different moments merge into one label, and what can still be recovered needs a separate check (Theorem 21.4). The time-embedding slider switches between the run clock and the lab clock, two arrangements of the same archive.
  8. Model limits. Paraxial Gaussian slits, a longitudinal envelope and a two-dimensional record space make a schematic model that guarantees only the qualitative structure and the identities above; it is not a numerical simulation of a real apparatus. “Switching spacetime” means switching the conditioned sub-ensemble and the time embedding.
