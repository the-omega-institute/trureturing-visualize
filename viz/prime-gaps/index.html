理论接口 · 这个页面在演示什么Theory interface · what this page shows

页面先在 2·107 以内筛出全部 1 270 607 个素数，下面所有计数都是直接数出来的。一组偏移量 H = {h₁, …, hk} 叫可容许元组，如果对每个素数 p，H 都没有占满模 p 的全部 p 个余数类；否则总有一个 n + h 被 p 整除，n + H 最多只有有限次全为素数。三维视图里，每个素数 p 是一圈 p 个槽，H 占用的槽亮起，空着的槽是绿色；一圈全被占满就是堵死。

  1. 可容许元组与最窄窗口（8 元组已冻结）。{0, 2, 4} 占满了模 3 的三个余数，除 3, 5, 7 外永远不会同时为素数。k 个偏移的可容许元组，最小宽度记作 s(k)（OEIS A008407）。本库证明 s(8) = 26：{0, 2, 6, 8, 12, 18, 20, 26} 可容许，而宽 25 的窗口里放不下 8 个可容许偏移（OptimalAdmissibleEightTuple.minimalAdmissibleDiameter_eight_26）。2·107 以内，这个 8 元组全为素数只出现两次：n = 11 与 n = 15 760 091。
  2. 有界间隙由两部分拼成（已冻结的拼接）。DHL[k, 2] 是说：每个可容许 k 元组 H，都有无穷多个 n 使 n + H 里至少两个是素数。再给一个宽 B 的可容许 k 元组，就得到无穷多个 ≤ B 的相邻素数间隙（DHLAdmissibleDiameterTransfer.dhl_two_and_admissible_window_yield_bounded_gap）。本库给出并核验了一个宽 186 的可容许 40 元组，所以 DHL[40, 2] ⇒ 间隙 ≤ 186 无穷多次（PrimeGap186TwoAxisAssembly.dhl40TwoNat_yields_gap186）；DHL[40, 2] 本身本库没有证明。文献上，Maynard 证明 DHL[105, 2]（Ann. of Math. 181, 383 (2015)），Polymath 证明 DHL[50, 2] 并得到 246（Res. Math. Sci. 1 (2014)）；第一个有界间隙结果是张益唐的 7000 万（Ann. of Math. 179, 1121 (2014)）。
  3. Hardy–Littlewood 预测（猜想，开放）。对可容许 H，猜想 n ≤ x 中 n + H 全为素数的个数约为 𝔖(H)∫2x dt/∏h∈H log(t + h)，其中 𝔖(H) = ∏p (1 − ν(p)/p)(1 − 1/p)−k，ν(p) 是 H 占用的模 p 余数个数。页面把实际计数和这条预测画在一起；连 k = 2 的孪生素数是否无穷多都还未知。
  4. 长间隙（已冻结）。Ford、Green、Konyagin、Maynard、Tao 证明：X 以下总有一个相邻间隙 > c·log X·loglog X·loglogloglog X/(logloglog X)²（J. Amer. Math. Soc. 31, 65 (2018)）；本库的版本移植自 openai/LongGapsBetweenPrimes（LongGapsBetweenPrimes.long_prime_gaps）。这条下界在 2·107 以内的数值没有意义（logloglog X 只有 1 左右），页面只画实际纪录、平均间隙 log p 与 Cramér 猜想的 log² p。
  5. A079063（已推翻）。a(n) 是使 √pn+k − √pn > 1 的最小 k。Cloitre 猜想存在 c > 0（可取 0.4）使 a(n) > c√n 最终总成立，并给出下极限约 0.46。本库证明不存在这样的 c（CloitreSquareRootPrimeGapRefutation.result）。由素数定理粗估 a(n) ≈ 2√pn/log pn，比值 a(n)/√n 像 2/√log n 那样极慢地趋于 0；在页面能算的范围（n ≤ 106）里它还在 0.4 以上，反驳来自证明，不来自这些数值。
  6. A089610（已推翻）。a(n) 是 (n², n² + n] 里的素数个数。OEIS 的猜想说从某个 n 起 a(n) < a(n + 1) 总成立。本库证明这不可能（HilliardSquareIntervalPrimeCountEventualIncreaseRefutation.result）；证明的一步是 a(2k) ≤ k（区间里只有 k 个奇数）。Oppermann 猜想 a(n) > 0 仍未解决。
  7. A049591 的一条刻画（已推翻）。A049591 是 p + 2 为合数的奇素数 p。Cloitre 提出：它恰好是那些 n > 1，使 n 与 n + τ(n)² 之间没有素数（τ 是因子个数）。529 = 23² 有 3 个因子，530 到 537 全是合数，但 529 不是素数（CloitrePrimeGapDivisorCharacterizationRefutation.result）。页面算到 2·105：最小的反例就是 529，一共有 9439 个不符的 n。
  8. 模型边界。所有计数都限于 2·107 以内；Hardy–Littlewood 曲线是猜想的预测，不是定理；比值 a(n)/√n 的粗估只是启发式。

The page first sieves all 1 270 607 primes below 2·107; every count below is a direct count. A set of offsets H = {h₁, …, hk} is an admissible tuple if, for every prime p, H misses at least one of the p residue classes mod p; otherwise some n + h is always divisible by p, and n + H is all prime only finitely often. In the 3D view each prime p is a ring of p slots, the slots occupied by H light up and the free slots are green; a ring with every slot occupied is a blockade.

  1. Admissible tuples and the narrowest window (the 8-tuple is frozen). {0, 2, 4} fills all three classes mod 3, so apart from 3, 5, 7 it is never all prime. The minimal width of an admissible k-tuple is written s(k) (OEIS A008407). This library proves s(8) = 26: {0, 2, 6, 8, 12, 18, 20, 26} is admissible, and no window of width 25 holds 8 admissible offsets (OptimalAdmissibleEightTuple.minimalAdmissibleDiameter_eight_26). Below 2·107 this 8-tuple is all prime only twice: n = 11 and n = 15 760 091.
  2. Bounded gaps come in two parts (the frozen assembly). DHL[k, 2] says that for every admissible k-tuple H, infinitely many n have at least two primes in n + H. Add one admissible k-tuple of width B and infinitely many consecutive prime gaps ≤ B follow (DHLAdmissibleDiameterTransfer.dhl_two_and_admissible_window_yield_bounded_gap). This library exhibits and checks an admissible 40-tuple of width 186, so DHL[40, 2] ⇒ gaps ≤ 186 infinitely often (PrimeGap186TwoAxisAssembly.dhl40TwoNat_yields_gap186); this library does not prove DHL[40, 2] itself. In the literature, Maynard proved DHL[105, 2] (Ann. of Math. 181, 383 (2015)) and the Polymath project proved DHL[50, 2], reaching 246 (Res. Math. Sci. 1 (2014)); the first bounded-gaps result was Zhang’s 70 million (Ann. of Math. 179, 1121 (2014)).
  3. The Hardy–Littlewood prediction (a conjecture, open). For admissible H the conjectured number of n ≤ x with n + H all prime is about 𝔖(H)∫2x dt/∏h∈H log(t + h), with 𝔖(H) = ∏p (1 − ν(p)/p)(1 − 1/p)−k and ν(p) the number of classes mod p occupied by H. The page draws the actual count against this prediction; whether there are infinitely many twin primes (k = 2) is still unknown.
  4. Long gaps (frozen). Ford, Green, Konyagin, Maynard and Tao proved that below X there is always a consecutive gap > c·log X·loglog X·loglogloglog X/(logloglog X)² (J. Amer. Math. Soc. 31, 65 (2018)); this library’s version is ported from openai/LongGapsBetweenPrimes (LongGapsBetweenPrimes.long_prime_gaps). The bound is numerically meaningless below 2·107 (logloglog X is about 1 there), so the page draws only the actual records, the average gap log p and Cramér’s conjectured log² p.
  5. A079063 (refuted). a(n) is the least k with √pn+k − √pn > 1. Cloitre conjectured that some c > 0 (0.4 would do) makes a(n) > c√n hold eventually, with a lower limit of about 0.46. This library proves that no such c exists (CloitreSquareRootPrimeGapRefutation.result). By the prime number theorem a(n) ≈ 2√pn/log pn, so a(n)/√n tends to 0 extremely slowly, like 2/√log n; in the range the page can compute (n ≤ 106) it is still above 0.4, and the refutation comes from the proof, not from these numbers.
  6. A089610 (refuted). a(n) is the number of primes in (n², n² + n]. The OEIS conjecture says that from some n on, a(n) < a(n + 1) always. This library proves that impossible (HilliardSquareIntervalPrimeCountEventualIncreaseRefutation.result); one step of the proof is a(2k) ≤ k (the interval contains only k odd numbers). Oppermann’s conjecture a(n) > 0 remains unsolved.
  7. A characterization of A049591 (refuted). A049591 lists the odd primes p with p + 2 composite. Cloitre proposed that it is exactly the set of n > 1 with no prime between n and n + τ(n)² (τ counts divisors). 529 = 23² has 3 divisors and 530 to 537 are all composite, yet 529 is not prime (CloitrePrimeGapDivisorCharacterizationRefutation.result). Computing up to 2·105, the page finds 529 to be the smallest counterexample, with 9439 disagreeing n in all.
  8. Model limits. Every count stops at 2·107; the Hardy–Littlewood curve is a conjectural prediction, not a theorem; the estimate for a(n)/√n is only heuristic.
